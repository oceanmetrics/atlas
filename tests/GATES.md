# GATES.md — the gates this repo carries, their seeded faults, and their CI wiring

Every gate ships with a seeded fault that proves it can fail (`CLAUDE.md`: a check that cannot fail is
not a check). Three patterns cover everything:

- **build-time invariant**: `scripts/<name>.mjs` (CLI) + `scripts/<name>-core.mjs` (pure) +
  `tests/<name>.test.ts` (drives the core function through synthetic fixtures, including a red one).
  `size-budget` additionally gets a real, CI-level red-fixture build (`pages.yml` builds
  `tests/fixtures/size-budget-{static-duckdb,worker}/` and inverts the checker's exit code against it).
  Current invariants: `size-budget`, `check-relative-assets`, `check-duckdb-ext`,
  `check-inlined-tokens`, `check-hex-literals`, `contrast`.
- **pure-logic / source-scan gate**: a `tests/**/*.test.ts` that asserts the real rule against real
  fixtures AND plants a fault (inline in the same file, or a committed fixture directory a scanner is
  pointed at, e.g. `tests/fixtures/map/fitbounds-fault/`) and asserts the checker rejects it.
- **source-edit seeded fault**: `npm run test:faults` (`scripts/test-faults.mjs`) worktrees HEAD,
  applies a committed unified diff under `tests/faults/*.patch` to the REAL file, runs the named gate,
  asserts RED, and discards the worktree. `npm run faults:check` is the cheap `git apply --check` over
  every patch.

## Fork note (OceanMetrics Atlas 0.1.0)

This repo was forked from MarineSensitivity/atlas 0.10.88, whose GATES.md inventoried ~120 gates. The
strip removed the Scores lens, Program Areas, the Report, the release gate and the gallery, and with
them every gate that only guarded those features. The Playwright-gated seeded faults were dropped too.
WP11 revalidated the inherited `e2e/` suite against the catalog-driven shell (Collections | Species,
tools Layers / Details / Table / Places): it is green in chromium (`npm run e2e:chromium`), hermetic (the
catalog, the MarineSensitivity STAC, the gazetteer manifest and every map origin are routed to fixtures,
`e2e/hermetic.ts`) and a MANUAL script, not a CI job: the whole directory (145 tests) takes about 4 minutes on an idle laptop (3:57
measured, 11 to 17 minutes while the machine was busy; every spec builds a software-GL map), over the 3
minutes that would justify adding it to `pages.yml`. Playwright-gated seeded faults are still not kept; re-add them with their specs as needed.
The upstream inventory is in the upstream repository's history.
